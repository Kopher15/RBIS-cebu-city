# Password file location (Windows)

Create this file:
  %APPDATA%\postgresql\pgpass.conf

Format (one line, no spaces around colons):
  localhost:5432:gis_db:postgres:YOUR_PASSWORD_HERE

Then verify:
  echo %APPDATA%\postgresql\pgpass.conf
  type %APPDATA%\postgresql\pgpass.conf

psycopg / libpq will pick this up automatically. Do NOT commit this file.
